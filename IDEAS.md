# Ideas

## Be generous about Refunds

Because these are digital classes, there is little lost by us if a Student or Purchaser decides part way in to cancel entirely, so we need to review later how to not be jerks about refunds and so on, and we should create a simple state machine design that manages options and transitions for the Seat Lifecycle.

## Reason checkboxes on cancellation

Cancellation reasons are free text for now and always will be. Once we've reviewed enough of them, add checkboxes for the common reasons alongside the free text.
